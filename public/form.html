¿Cómo tomar fotos 360°?
📱 iPhone: Abrí la app Cámara → modo Panorama → girá despacio 360°
📱 Android: Usá la app Google Street View → ícono de cámara → modo Esfera
📸 Resultado: Una foto ancha (2:1) que se verá con efecto inmersivo en el tour virtual
MP4 recomendado. Máximo 100MB.
¿Cómo obtener el código?
📘 Facebook: Abrí la publicación → tres puntos (...) → Insertar → copiá el código iframe
📸 Instagram: Abrí la publicación en web → tres puntos (...) → Insertar → copiá el código
